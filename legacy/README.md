# Legacy site archive

This directory preserves the previous Jekyll / Bootstrap template, its example posts and tutorials, and the former Chinese site. It remains under Git version control for recovery and is excluded from the GitHub Pages build by `_config.yml`.

The current homepage uses `index.html`, `assets/`, `img/snowboarding.jpg`, `cv/`, and `content/`. Nothing in this archive is needed to generate or display the current homepage. Common old routes are served by small redirect pages outside this archive.

https://github.com/jmcglone/jmcglone.github.io
https://creativecommons.org/licenses/by/3.0/

Do not restore archived analytics or comment-service identifiers into the current site. Files here are historical references and may contain outdated personal information or links.
